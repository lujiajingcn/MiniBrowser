## MiniBrowser 修复：页面中的链接打不开（根因 + 排除的假假设）
- 用户反馈「浏览器无法打开页面中的链接」。判定方法改为**统计标签数量**（写在 `main.js` 的 `runDemoSequence` 里，保留为诊断能力）：点击前后各取一次 `document.querySelectorAll("webview").length` 与各 `src`，得出 `NEW_TAB` / `NAVIGATE`（原地跳转）/ `NO_OP`（点击被吞）。
- **真根因 1（已修）**：`main.js` 的 `setWindowOpenHandler` 原先对所有 webContents 一律 `{action:'deny'}`。页面用 JS `window.open()` 打开的链接（百度/新闻站大量使用）因此被静默吞掉、`window.open` 返回 `null`，用户侧表现为「点了没反应」。
  修复：把 http(s) 目标 URL 通过 `win.webContents.send('mb-open-in-tab', url)` 转发给宿主窗口，由渲染进程 `createTab(url)` 开新标签后再 deny 原生窗口。注意 webview 的 guest contents 需经 `contents.hostWebContents` 才能被 `BrowserWindow.fromWebContents()` 识别。
- **真根因 2（已修，原为死代码）**：`will-attach-webview` 里基于 `webPreferences.preload` 的「preload 白名单」在 Electron 31 **永不成立**——实测该对象字段仅 `nodeIntegration / nodeIntegrationInSubFrames / plugins / zoomFactor / disablePopups / webSecurity / enableBlinkFeatures / disableBlinkFeatures / partition / contextIsolation / sandbox`，**没有 preload**（preload 在事件第三个参数 `params.preload`）。该分支每次误走「剥离」，实为空转。改为施加真正生效的加固（nodeIntegration=false、nodeIntegrationInSubFrames=false、contextIsolation=true、webSecurity=true、sandbox=true、allowRunningInsecureContent=false）。
- **被证伪的假设（重要，别再踩）**：曾判定「contextIsolation 下 `el instanceof HTMLAnchorElement` 跨世界必然失效」。**实测证伪**——把旧 `instanceof` 写法放回生产跑对照实验，结果同样是 `NEW_TAB`，说明 Electron 31.7.7 隔离世界里该写法可用。现统一改用 `nodeType + tagName` 字符串判定（不依赖构造函数身份、更稳健），但注释已更正，不再声称 instanceof 失效。
- **另一个真实陷阱**：Electron 20+ 起 `sandbox` **默认为 true**。窗口若未显式 `sandbox:false`，预加载走沙箱路径，只能 `require('electron')`，`require('node:path')` / `node:url` 会抛 `module not found: node:path`（堆栈含 `preloadRequire` / `sandbox_bundle`），导致 `contextBridge` 从未执行、`window.electronAPI` 为 undefined。连锁后果：webview 拿不到 preload 属性（链接拦截失效）、`getLaunchUrl()` 失效（永远回落 HOME_URL）、`createWindow` 静默失效。生产 `main.js` 已显式 `sandbox:false` 故不受影响，但**自建诊断窗口忘了设，导致前两轮测试结论失真——诊断入口必须逐项复刻生产的 webPreferences**。
- 捕获预加载报错：`win.webContents.on('preload-error', (e, path, err) => ...)` + `console-message` 事件。
- 改动文件：`main.js`（弹窗转发 + 加固 + tabReport 诊断 + 移除未用的 pathToFileURL 导入）、`preload.js`（新增 `onOpenInTab` 通道）、`renderer.js`（监听 `mb-open-in-tab` → `createTab`）、`webview-preload.js`（tagName 判定 + 去掉失效的 window.open 改写 + 新增 Ctrl/⌘+左键）。
- 验证：生产入口 + 全新 profile；本地 http 测试页覆盖普通链接 / `target=_blank` / 命名 target / JS `window.open`；最终真机回归用百度——点击「新闻」后 `tabs 1 → 2`，srcs 为 `[baidu, news.baidu.com]`，`NEW_TAB`。`npm run lint` 通过。
- 清理：临时诊断文件（`test-link-main.js`、`serve-test.js`、`test-links.html`、各 `*.log`、`test-profile-*`、离屏黑屏 PNG）已全删；保留 `final-before.pdf` / `final-after.pdf` 作为修复证据。
